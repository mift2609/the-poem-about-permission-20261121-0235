A short poem about agency: the power to ask and to be given. A knock,
a door opened by someone else's hand, a cup held out empty and filled —
and the yes that follows, held open for the next knock.

`main.py` (Python 3.13, standard library only) writes the poem to
`/output/entry.txt`. Run it locally with:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

inside the 1–280 gate, and not only white space.
